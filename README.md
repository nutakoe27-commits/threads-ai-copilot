# GTM-система: утренний список лидов

Система находит компании, подходящие под ICP, собирает по каждой досье
с сайта, пишет письмо и кладёт всё в утренний список — файлом, в Telegram
и в локальную панель с кнопками.

> **Первый запуск на macOS — [START.md](START.md).** Пошагово, с нуля,
> с проверкой после каждого шага.

| Документ | О чём |

## Что уже работает

- **Целевой список** через Checko: ОКВЭД, регион, штат, выручка, динамика,
  выручка на сотрудника. У каждой отсеянной компании записана причина.
- **Досье** с сайта компании: факты подтверждаются цитатой со страницы,
  иначе не сохраняются. Плюс технографика — счётчики, коллтрекинг, виджеты.
- **Письма и дожимы** по устройству из пяти частей: вопрос про их работу →
  что делает Михаил, с признаками их покупателя → пилотный список →
  просьба. Факт из досье должен попасть в текст, иначе письмо откладывается.
  Сокращения (ЛПР, CRM, лид, воронка) ловит код, а не только промпт.
- **Балл схождения сигналов** — по нему сортируется список. Веса в конфиге.
- **Учёт**: статусы касаний, воронка по дням, предупреждение при падении
  конверсии вдвое, вечный стоп-лист.
- **Панель** на `127.0.0.1:8765` — вся работа отсюда: запуск этапов кнопками
  с полосой прогресса и живым логом, письма со статусами, воронка, правка
  настроек и текстов писем, логи с фильтром.

## Состояние по источникам сигнала

Событийных источников два: страница вакансий на сайте самой компании
и реестр отечественного ПО Минцифры. trudvsem замером забракован (Р-014),
hh.ru закрыт на уровне соглашения разработчика (Р-016), Perplexity закрыт
замером (Р-029). Подробности — в [DECISIONS.md](DECISIONS.md).

## Установка

Пошагово, с нуля, для macOS — в [START.md](START.md). Коротко:

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # вписать ANTHROPIC_API_KEY и CHECKO_API_KEY
python3 selftest.py       # офлайн-проверка логики, в сеть не ходит
python3 run.py --stage ui # панель на http://127.0.0.1:8765
```

Ключ Checko: регистрация на [checko.ru](https://checko.ru) даёт **100 запросов
в сутки бесплатно**.

## Работа через панель

`python3 run.py --stage ui` → **http://127.0.0.1:8765**

| Вкладка | Что там |
|---|---|
| Прогон | кнопки этапов, полоса выполнения, живой лог, остановка |
| Письма | готовые письма, кнопка копирования, статусы |
| Воронка | конверсии по дням и предупреждение о падении |
| Настройки | критерии, веса, лимиты и все тексты писем |
| Логи | последние записи с фильтром по уровню и этапу |

Порядок этапов сверху вниз на вкладке «Прогон» — это и есть порядок
ежедневной работы. У каждого этапа есть кнопка «проба»: делает всё,
кроме записи.

Панель слушает только `127.0.0.1`. Отсюда запускаются прогоны и правятся
настройки, поэтому наружу её выставлять нельзя. Ключи из `.env` панель
не показывает даже на чтение.

## Работа из терминала

Те же этапы, те же функции — командная строка и панель зовут один и тот же
`src/pipeline.py`.

```bash
python3 run.py --stage targets     # найти компании
python3 run.py --stage dossier     # обойти сайты и собрать досье
python3 run.py --stage compose     # написать письма
python3 run.py --stage followup    # дожимы тем, кто не ответил
python3 run.py --stage morning     # собрать утренний список
python3 run.py --stage stats       # воронка и самодиагностика
python3 run.py --stage mark sent 7703283933   # отметить статус
python3 run.py --dry-run --stage dossier      # ничего не записывать
python3 selftest.py                # проверить логику без обращения к сети
```

Полный список — `python3 run.py --help`.

Коды возврата: `0` — всё хорошо, `2` — были ошибки, `1` — необработанное
падение. Двойка заставит cron прислать письмо, а «сегодня новых компаний
нет» — нет.

**`python3 selftest.py` стоит запускать после каждой правки конфигов.**
Он уже ловил настоящие ошибки: конфликт стоп-слова «водитель» внутри
«руководитель отдела продаж», письма, которые молча писала дешёвая модель
вместо сильной, и порог фактов, отбрасывавший хорошие письма.

## Что настраивается без правки кода

Всё это правится на вкладке «Настройки» или прямо в файлах:

- `config/icp.yaml` — отрасли, регионы, штат, выручка, веса баллов,
  лимиты запросов, настройки панели;
- `config/prompts/letter.md` — устройство письма и запреты;
- `config/prompts/offer.md` — что предлагаем и о чём просим;
- `config/prompts/origin.md` — подпись и контакты;
- `config/prompts/angles/*.md` — угол разговора по типу компании;
- `config/signals.yaml` — ключевые слова сигналов;
- `data/stoplist.txt` — ИНН, которым больше не пишем. Правило вечное:
  отказался — больше никогда.

Перед записью из панели содержимое проверяется, а прежняя версия уходит
в `data/config-backups/`.

## Границы: чего система не делает

- **Не отправляет письма.** Готовит текст, отправляете вы, из своего ящика.
- **Не хранит имена людей.** Только реквизиты юрлица и обезличенные
  корпоративные адреса. Имя адресата подставляете руками (Р-000).
- **Не ходит в hh.ru автоматически.** В списке есть ссылка на поиск,
  которую вы открываете сами (Р-001).
- **Не обходит robots.txt** и не ходит к чужому сайту чаще раза в две
  секунды. Эти ограничения нельзя ослабить через настройки (Р-043).
